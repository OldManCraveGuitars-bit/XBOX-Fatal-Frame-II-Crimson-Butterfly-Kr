# v0.8 검증 범위

- 실제 배포 Windows EXE로 지원 일본판 ISO에서 전체 결과 XISO 재생성 및 전체 SHA-256 일치.
- 재생성 ISO를 독립 파서로 다시 열어 4,157개 경로·크기·해시 확인. 99개 변경, 4,058개 동일.
- XBE 원본과 바이트 일치, 원본 매체 설정 0x00000202 유지. HDD 허용 패치 없음.
- 패처 보호 검사 9개: 원본/기존 출력 보호, 잘못된 입력·손상 차분·손상 디코더 거부, 실패한 임시 출력 정리 등.
- 메시지 5,492개와 포인터 표 85개, 공유 포인터·종결 문자·제어 명령 유지.
- 공백 F3AB의 원본 10px 진행, 한글 24px 진행, 안전한 원본 폰트 뱅크 사용. F4 미사용.
- 선택 칸 42곳 길이 제한과 설정 설명 두 줄 제한. 문구 4,542개 자동 줄/높이 검사에서 초과 0.
- 본문 6,052개 고유 줄·3,630개 페이지를 원본 문자 처리 코드로 PC 실행 검사. GPU 호출은 모의 처리.
- 생성 글리프 839개의 실제 RGB가 원본 일반 글자 계열인 128/128/128임을 검사. 엔진이 주변 글자색을 적용함.
- 한글 837자의 셀 여백, 기존 아이콘 픽셀과 원본 팔레트 보존 확인.
- 이미지 2,446개 및 메시지·기존 자막의 무수정 재삽입 바이트 일치 검사 기록 유지.
- 변경 이미지 컨테이너 98개 내 텍스처 691개의 길이·형식·크기·오프셋·밉 수 유지.
- 메시지 232,732바이트 / 섹터 읽기 233,472바이트. 다음 알려진 고정 버퍼 전 16,384바이트 여유.
- 전체 힙 할당과 모든 간접 참조를 증명한 검사는 아님. 변경 대상 밖 진행·음성·영상·저장 식별 정보 유지.
- 원본 자막 등록 표 71개, 구간 포함 표 44개, 원본 253구간과 음성 자막 표 변경 없음.
- 엔딩 3곳의 마지막 대사에 크레딧 둘째 줄 추가. 원본 코드의 NTSC/PAL·켜기/끄기·구간 경계 48개 조건 검사.
- ZIP 무결성과 내부 EXE·사용법·라이선스의 개별 체크섬 검사.

## 실행 확인과 남은 범위

이전 빌드의 타이틀·설정·초반 메뉴에는 실제 Android GPU 확인 기록이 있습니다.
v0.8 최종 리소스는 PC 코드·픽셀·ISO 검사까지 확인했습니다. 새 기기 접속·게임 실행은 하지 않았습니다.
검증 JSON은 이를 구분하고 완성 여부를 false로 기록합니다.

전편 수동 번역 대조, 모든 이미지 일본어, 해금·획득 후 상세 메뉴, 전체 음성 동기,
전편 진행·저장/불러오기, 최신 수정본의 GPU 표시는 추가 확인 대상입니다.
홍보영상 promo_01/02/03에는 원본 자막 구간이 없고 새 한국어 자막을 추가하지 않았습니다.
크레딧은 자막을 켜야 보이며 마지막 대사와 약 2.7~3.2초 함께 표시됩니다. 스태프롤 끝 독립 카드는 아닙니다.
