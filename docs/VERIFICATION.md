# 검증 범위

## 배포 파일

- 배포 EXE가 지원 일본판 원본을 읽어 만든 XISO의 전체 SHA-256이 README의 결과 해시와 일치.
- 파일 목록 4,157개, 차분 변경 파일 100개. 원본과 동일한 파일 4,057개.
- 원본 파일·기존 출력 덮어쓰기 거부, 다른 크기/해시 원본 거부, 손상 차분/디코더 거부, 실패한 임시 출력 정리 검사.
- ZIP 내부 EXE·사용법·고지의 해시와 ZIP 무결성 검사.

## 한글화 데이터

- 메시지 5,492개·포인터 표 85개, 공유 포인터·종결 문자·색/변수 제어 명령 유지.
- 본문 5,960개 고유 줄·3,627개 페이지를 원본 문자 처리 코드로 실행 검사.
- 한글 837자의 원래 크기 렌더링과 24px 셀 투명 경계 확인, 공백12px/한글 진행22px.
- 이미지 2,446개와 메시지·기존 자막의 무수정 재삽입 바이트 일치.
- 변경 이미지 컨테이너98개 내부691텍스처의 파일 길이·오프셋·형식·크기·밉 수 유지.
- 원본 로더의 직접/캐시 읽기 두 방식에서 변경 리소스99개의 읽기 크기 정상. 원본 대비 신규 누락0.
- 메시지의 실제 읽기212,992바이트, 다음 알려진 고정 버퍼까지36,864바이트 여유. 전체 힙 할당과 모든 간접 참조를 증명한 것은 아님.
- XBE 헤더·아이콘·섹션 해시 정상. UI 중심 좌표·글꼴·자막 패치 밖 코드 변경 없음. 원본 Title ID와 저장 식별 정보 유지.
- 영상71트랙256구간, 원본 구간 타이밍과 기존 음성 자막 바이너리 유지.

## 최근 UI 수정

- 일반 모드 전체 문구를 첫126px 스프라이트에 native21px로 다시 조판, 남은44px 조각 투명 확인.
- 원본 옵션 함수0x25830과 글자 폭 함수0xCBE80을 PC CPU로 실행. 7개 선택 상태·2개 토글 상태에서 켜기/끄기의 글자와 그림자 중심 일치.
- 프레임 보호4영역은 조판 이미지와 실제 재삽입 RGBA 바이트가 일치.
- 접합부34열의 양쪽 픽셀과 바깥 필터 여백까지 색/알파 일치.

## 실제 화면과 한계

저장소의 게임 캡처는 이전 빌드에서 확보한 타이틀·설정·초반 메뉴의 실제 Android GPU 화면입니다.
최종 v0.75의 최근 세 UI 수정은 PC 코드/픽셀/ISO 검사까지 확인했으며 새 기기 접속·게임 실행은 하지 않았습니다.
정적 리소스 비교와 실제 게임 캡처를 README에서 구분했습니다.

수동 대조는 주요 그룹1,475개 고유 원문/번역 쌍까지 진행했습니다. 전편 모든 문장·책등/설정화의 이미지 일본어·
모든 자막 음성 동기·전편 진행·저장/불러오기·해금 메뉴가 전부 검증됐다는 뜻은 아닙니다.
