# hakuX Integrated QA

원 개발자의 공식 배포가 아닌 **hakuX 1.3.0 기반 비공식 통합 테스트판**입니다.
기존 `hakuX FFII QA`와 같은 식별자·서명으로 업데이트되며 앱 이름이
`hakuX Integrated QA`로 바뀝니다. 공식 hakuX와 기존 Spikeout QA는 별도 앱입니다.

- 패키지: `com.rfandango.haku_x.ffiiqa`
- 버전: `1.3.0-integrated-qa1` / code 10
- 확인 기기: Retroid Pocket Nova / Android 13 / Adreno 740
- 드라이버: 기존 Turnip Gen8 V38. 시스템 GPU 드라이버나 펌웨어를 고치지 않습니다.
- 설치: APK를 기기에 옮겨 설치한 뒤, 게임 폴더를 지정하고 보유한 ROM을 실행합니다.
  신규 설치는 사용자 설정과 Vulkan 드라이버 선택이 필요합니다.

## 통합 내용

1. 령2: 겹친 렌더 타깃의 전체 쓰기 순서 대신 실제 겹친 영역의 쓰기 순서를 비교해
   촬영 화면이 반복 합성되면서 하얗게 타는 현상을 수정합니다.
2. 귀무자: RAM에서 깊이 버퍼로 복사된 D24S8 배경 가림 데이터를 실제 Vulkan
   깊이 이미지에도 반영합니다. 부분 복사 바깥의 깊이·스텐실을 보존하고 확대 시
   최근접으로 복제합니다. 특정 상자나 몬스터를 강제로 숨기는 방식이 아닙니다.
3. 스파이크아웃: 실행 파일 구역 제한256→512. 일본판398개/한글판399개를
   읽을 수 있게 했던 기존 로더 수정을 포함합니다. 기존 R8 자동 설치는 포함하지 않습니다.

## 검증 범위

- 귀무자: 같은 장면의 벽 뒤 상자·붉은 물체가 가려지고 앞 캐릭터는 표시됨.
  1x/3x 확인, 기기 앱에서 약60FPS 및 인접 방 화면 확인.
- 깊이 복사를 비대칭 네 조각으로 나눈 결과가 전체 복사와1x/3x 각각3프레임에서
  픽셀 단위로 동일했습니다. 해당 장면의 부분 복사 경계를 확인한 검사입니다.
- 령2: 같은 저장 지점에서 백화가 사라지고 문과 초록 조준원이 보임.
  기기 앱3x, 촬영 모드 끄기/켜기 확인.
- 스파이크아웃: 기기에서 통합 코어로399개 구역을 해석하고 부팅 영상 및
  한국어 플레이어 선택/이름 입력 화면까지 확인. 업데이트 앱에서 아이콘 표시.

귀무자 특정 몬스터 조우, 령2 귀신 조우, 스파이크아웃 전체 플레이와 전 게임
전체 구간은 미검증입니다. 새 깊이 업로드는 선형 정수 D24S8 경로를 대상으로 합니다.
